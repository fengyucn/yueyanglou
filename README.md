背《岳阳楼记》免岳阳楼门票（70元）的背诵辅助工具。

范仲淹写这篇文章的时候肯定没想到，一千多年后有人靠背它省 70 块钱门票。

## 功能

- **默写模式**：完全凭记忆输入
- **填空模式**：保留标点和每句首字，其余挖空
- **首字提示**：只显示每句首字，补全其余
- **逐字比对**：基于 LCS 算法，精准标记正确/错误/缺漏/多余
- **同音字检测**：内置 25 组易混淆同音字，标记提示
- **分段背诵**：全文 6 段逐段检查
- **统计评分**：每段 + 最终总正确率

## 使用

直接打开 `index.html` 即可，无需任何构建或服务器。
